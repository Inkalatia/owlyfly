如何运行网页版How to run the web version
  1. 下载并解压压缩包 Download and extract the archive
  2. 双击运行 owlyfly.bat Double-click owlyfly.bat to run it
    （服务器会在后台启动，窗口会在10秒后自动关闭） (The server starts in the background; the window closes after 10s)
  3. 必须使用 Firefox 浏览器 — 其他浏览器（Chrome、Edge 等）暂不支持 Must use Firefox — other browsers (Chrome, Edge, etc.) are not supported
    下载 Firefox Download Firefox
  4. 在 Firefox 地址栏输入 http://localhost:8000 Type http://localhost:8000 in the Firefox address bar
    （如果 Firefox 不是默认浏览器，请先打开 Firefox 再输入地址） (If Firefox is not your default browser, open Firefox first then enter the address)
  5. 开始游戏！🎮 Start playing! 🎮

提示：服务器运行在端口 8000，确保该端口未被占用。 Tip: The server runs on port 8000, make sure the port is not occupied.
